# SP2-A 报告目录

本目录只存放 SP2-A（真实 KG 环境验证及其补充）实验报告。

- `SP2A_experiment_report.md`：人类可读结论（主实验 E2A.1–E2A.7 + 第 13 节补充）
- `metrics.json`：机器可读指标与哈希；`report_sha256` 为上述报告冻结后的 SHA-256
- 核对应使用仓库内 LF 字节（`sha256sum SP2A_experiment_report.md`）。CRLF 转写会得到另一哈希，不能用来否定收口登记

- 补充实验：`sp2a-supp-20260822T111116Z-79aa8ea8`
